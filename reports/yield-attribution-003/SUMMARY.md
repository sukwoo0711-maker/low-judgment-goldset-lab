# 수율 손실 직접 귀속 003

## 결론

사유 코드를 켠 상태로 GPU 복구 후 재실행했고, **`invalid`의 원인을 처음으로 직접 귀속했습니다.**

거부의 **84.5%가 표면형 게이트 두 개**에서 발생합니다. 사실 추출이나 JSON 형식이 아니라, 모델에게 요구한 표면형 변형을 모델이 만들어내지 못해 후보 전체가 버려지고 있었습니다.

## 실행 조건

| 항목 | 값 |
|---|---|
| 실행 | `full-candidates-v4` |
| 모델 | `qwen2.5:7b` |
| GPU | RTX 3070 Ti 8GB, 드라이버 591.86 (재부팅으로 복구) |
| 시도 | 142 (전체 1,017청크 중 중단) |
| 중단 사유 | 실행 세션 종료와 함께 프로세스 종료. 코드 오류 아님 |

## 상태 분포

| 상태 | 건수 | 비율 |
|---|---:|---:|
| invalid | 81 | 57.0% |
| valid | 35 | 24.6% |
| explicit_skip | 24 | 16.9% |
| error | 2 | 1.4% |

유효율은 v1의 19.5%에서 24.6%로 올랐습니다. 청크 순서와 seed가 달라 직접 비교는 조심해야 합니다.

## 거부 사유 직접 귀속

`invalid` 판정을 받은 시도의 패스별 사유입니다(162 패스).

| 사유 | 건수 | 비율 |
|---|---:|---:|
| `spacing_has_no_marker` | 88 | **54.3%** |
| `mixed_has_no_latin` | 49 | **30.2%** |
| `queries_not_four` | 14 | 8.6% |
| `duplicate_query_text` | 11 | 6.8% |

**표면형 게이트 둘이 84.5%를 차지합니다.** 나머지 15.5%만이 형식 오류(질의 개수)와 중복입니다.

전체 패스 기준으로 보면 `explicit_skip` 21.4%, `ok` 14.6%가 추가됩니다. 즉 모델이 근거 부족으로 스스로 물러난 경우보다, 표면형 요구를 못 맞춰 버려진 경우가 훨씬 많습니다.

## 이 숫자가 뒤집는 것

[변형 001](../variants-001/SUMMARY.md)에서 결정론적 변형을 도입할 때, 근거로 든 것은 확장 배수 4.33×였습니다. 심문 과정에서 "모델이 띄어쓰기 변형을 만들지 않는다"는 해석과 "적용률 100% 대 6.1%" 비교는 모두 철회했습니다. 근거가 통과 사례에서 얻은 간접 증거였기 때문입니다.

이번 측정은 간접 증거가 아닙니다. **거부된 시도에서 직접 센 값**이며, 앞서 철회한 주장보다 훨씬 강한 형태로 같은 결론을 지지합니다.

- `spacing_has_no_marker` 54.3% — 모델이 띄어쓰기·약어 표면을 만들지 못해 후보 전체가 버려진다
- `mixed_has_no_latin` 30.2% — 한/영 혼합 표면도 마찬가지다
- 두 축 모두 [결정론적 변환](../variants-001/SUMMARY.md)이 추가 추론 없이 만들어내는 축이다

여기에 [002의 구조적 발견](../yield-attribution-002/SUMMARY.md)을 겹치면 상황이 분명해집니다. 띄어쓰기 축은 **설령 모델이 만들어내도** `duplicate_query_text`에 걸려 통과할 수 없습니다. 모델은 통과 불가능한 요구 때문에 거부되고 있었고, 그 거부가 전체 손실의 절반 이상입니다.

## 코퍼스 규모 — 목표 미달이 확정적이다

| 항목 | 값 |
|---|---:|
| 문서 | 40 |
| 청크(120자 이상) | 1,017 |
| 관측 유효율 | 24.6% |
| 기대 클러스터 | 약 250 |
| 기대 질의(모델 4종) | 약 1,000 |

경계선입니다. 유효율이 24.6%를 유지하면 겨우 1,000에 닿고, v1의 19.5%로 돌아가면 약 790에 그칩니다. **코퍼스가 목표를 여유 있게 지지하지 못합니다.**

결정론적 변형을 실행 경로에 연결하면 자연질의 250건만으로 1,000을 넘깁니다. 그러려면 계약 개정(4의 배수 제약, 클러스터당 4질의, full gate의 질의별 사람 `Y`)이 선행되어야 합니다.
